# 石家庄潮流前端

在仓库根目录执行 `python start_api.py`，打开 <http://127.0.0.1:4173/>。

页面默认显示 13 点原始断面的已保存结果。运行按钮创建真实 Python 计算任务；右侧同时展示所选元件状态与后端 SSE 日志，拓扑动画跟随任务运行和已计算的潮流方向。没有额外延时来模拟计算。

数据集可选择内置 13 点、20 点，或导入 DAT 所在文件夹。算法可选普通牛顿、阻尼牛顿、解耦启动加牛顿。现场计算的完整结果替换页面数据，同时保留原始输入哈希、时间、残差、迭代次数和分区误差。

`python web_sjz/build_data.py` 使用同一计算入口重建 `data.js`。`styles.css` 为白底界面样式。

本地服务按资源内容生成版本地址，防止重构后旧脚本缓存与新页面混用。页面分别提示脚本加载、服务连接及失败状态；接口请求超时会给出错误信息。

坐标是电气布局，并非真实 GIS；PCC 为等值接口标识，不额外改变原始断面注入。文档和历史报告见根目录 `doc/`。
