# 石家庄潮流前端

在仓库根目录执行 `python start_api.py`，打开 <http://127.0.0.1:4173/>。

页面打开或刷新后均为空白待上传状态，不读取历史结果，也不恢复上次上传选择。没有默认数据集；“运行潮流校核”在成功上传并识别 DAT 前不可用。

点击“选择数据文件夹”，选择原始 `raw_dataset/extracted/`。一个上传文件夹登记为一套数据集，页面显示其 DAT／馈线表／目录组成与完整清单；13:00／20:00 是同一数据集里的计算时刻，通过按钮选择。多个断面时必须手动选择，单个断面自动选中；无时刻标记的 DAT 按文件名显示。切换时刻会清空旧结果。原始 13 点为 2,121 母线、20 点为 2,122 母线。复制扩展算例已从应用入口移除，带扩展标记的文件不能上传。

也可点击“上传压缩包”，选择 ZIP、TAR、TAR.GZ 或 TGZ。一个包导入为一套数据集，只读取其中 DAT/XLS/XLSX，保留子目录、中文文件名和原始文件字节；包内没有统一顶层文件夹时，以包名添加数据集目录。上传及解压后总大小均限 32 MiB，单个数据文件限 16 MiB，最多 500 个数据文件；拒绝加密包、路径越界和链接文件。ZIP 支持 UTF-8 与常见 GBK 中文文件名。

算法默认“加权分区 + 并行 Newton–Schur”，还可选择普通牛顿、阻尼牛顿、解耦启动加牛顿。运行按钮创建真实 Python 任务，日志显示三阶段、边界修正、分区残差、实际线程编号及耗时。T 卡阻抗按用户指定的 100 MVA 假设换算，L 卡按文件系统基准；原文件、负荷、控制及额定容量不变，过载不截断。页头和运行记录标明这一建模假设，顶部主指标为 T 支路最高电流负载率，副指标显示线路最高值；元件详情与 CSV 保留两种负载率及原始／换算后 R/X。

分区和消元结构可在严格核对后复用，潮流结果和数值 LU 不缓存；每次重新读取 DAT、组装数值矩阵并从平坦初值开始。运行记录增加分区准备、消元结构准备、迭代及遥测耗时，日志注明本次构造还是复用结构索引。超过 512 母线时逐轮状态采用无损 float64 编码传输，节点状态及回放内容完整保留。

顶部集中上传、时刻、算法和运行按钮，文件清单及输入范围在“数据集详情”中查看。桌面拓扑随可用高度调整，与运行按钮保持在同一屏；小屏幕使用置顶运行栏。

上传区依次显示文件准备、实际传输字节进度、服务端解包／识别和导入结果。传输达到 100% 只表示请求文件已传完，识别成功后才标为“导入完成”；失败时保留原有数据集并允许重试。顶部“本次总用时”从点击运行计到结果就绪，结束后冻结同一计时值；小字明确“后端处理包含数值求解”，二者不能相加。

点击总用时旁的“明细”，查看四个互不重复的分项：服务器排队、数值求解、后端其他处理、通信与页面等待。后端其他处理包含读取、建模、分区、结果生成及结果 JSON 保存，不重复计入数值求解；通信与页面等待是页面总用时减去服务器实测时间的差额，包含请求、SSE、结果响应编码与下载、浏览器处理等，不能将该差额单独归因于网络。服务端通过同一单调时钟分别记录排队、执行、保存和就绪时间；持久化在任务的 `timing.json` 中，接口及日志下载返回 `run.service_timing`，归档任务仍保留这些计时。完整记录也可在“本次运行记录”中查看。实时日志保留三阶段事件，右侧已移除三阶段标签条。

点击节点显示所属分区、内部／边界角色与邻区，并高亮拓扑。右侧分区明细显示逐轮残差、局部线程、边界两侧 P/Q 及两端和。电流动画覆盖当前图层中全部可见、有电流的线路及变压器，不再抽样或绘制虚构协调飞线；零电流支路静止，方向依据 P（纯无功时依据 Q），速度为展示示意。计算结束即停止自动动画，可手动勾选“电流动画”查看最终结果。“迭代记录”默认收起且不会自动播放，手动回放不增加后端计算耗时。迭代节点 P/Q 为理想连接合并组注入，最终恢复原始节点注入。

结果表支持分页、搜索和完整 CSV 导出；下载日志包含本任务全部结构化事件。上传按原字节保存到 `runtime/uploads/`，不会覆盖源文件。18 份馈线详细表和 1 份目录属于原始数据集，但当前未接入求解模型；文件清单、页面说明、后端日志及运行记录均注明本次只读取所选 DAT。普通牛顿不追加固定边界局部验证。

历史 `data.js` 快照不再由网页加载。服务按资源内容生成版本地址，避免旧脚本缓存；页面分别提示脚本、连接和任务失败。拓扑坐标为电气布局，并非实地 GIS；PCC 为假设接入点，不展开微网内部网架或增加注入。
