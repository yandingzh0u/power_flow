1. 静态电压相关负荷模型 (ZIP Load Model)
PL = P0 ( ap V² + bp V + cp )
P_L, Q_L: 节点的实际有功/无功负荷
P_0, Q_0: 在基准电压下的额定有功/无功负荷

PDER ∼ N( μP , σP² )

μ_P: 日前/日内气象预测下的期望出力均值
σ_P²: 反映预测误差的不确定性方差(可通过场景集Ω量化)

3. 柔性电力电子设备可控度指标 (Flexibility Index)
Ci = α ΔQiSi + β ΔPiSi + γ 1Tres,i
C_i: SVG/SOP/储能等设备综合可控能力评分
ΔQ_i, ΔP_i: 设备可提供的四象限无功/有功调节裕度范围
S_i: 该柔性设备的额定视在功率容量
T_res,i: 设备响应控制指令的时间尺度(逆变器极快，OLTC较慢)
α, β, γ: 运行者赋予无功、有功及响应速度的权重偏好
4. 多维特征驱动的图划分目标函数 (Partition Objective)
min Φ = ∑k=1K ( α Ccalc,k + β Uk + γ Bk + δ Delec,k + η Rctrl,k )
C_calc,k: 第k分区的算力计算复杂度估计(追求各区负载均衡)
U_k: 第k分区的源荷不确定性聚集度(避免高波动源扎堆)
B_k: 跨分区边界割裂惩罚数量(降低通信与协调压力)
D_elec,k: 子区内部的电气距离紧密度(确保子区强耦合)
R_ctrl,k: 子区内包含的柔性资源可控能力(提升局部收敛性)

设备可控度 C_i 权重系数

有功调节比重 (β)0.4
响应速度比重 (γ)0.2
